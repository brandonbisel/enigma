# CLAUDE.md

See [AGENTS.md](AGENTS.md) for how to work in this repository — commands, layout,
conventions, the domain rules that are easy to get wrong, and the traps in the
build. It applies here in full; there are no Claude-specific instructions.

One rule outranks the rest and is repeated here because this file is always in
context: **no cipher data ships unless it is pinned to a published source or a
published vector.** Wirings, notches, tables, calendars, key sheets, vectors and
language statistics all count as cipher data. Never write one from memory — a
plausible reconstruction does not fail loudly, it produces convincing wrong output.
If a source is not at hand, say so and stop rather than supplying the data. The
working form of the rule is the first section of AGENTS.md; the full statement and
every source is in [docs/sources.md](docs/sources.md).
