# The set skips I throughout, as these booklets do, so P is the fifteenth and last
# table of the set, and this completes it.
#
# Two cells were adjudicated rather than read, and the involution named both. The
# X of JV is blotted and the letter before it lost its foot to the same ink, so it
# read I; LX reads JV, and of the 676 values LX is one of only two nothing else
# claims, so JV is LX. The second letter of ZY inked closed and read B; AE reads
# ZY, and AE is the other unclaimed value, so ZY is AE. It is the B/E confusion
# that heads the pipeline's list, and the I/L one beside it.
#
# The other 674 entries came through on a first reading, every mirror agreeing,
# no fixed point.
