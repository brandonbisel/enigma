# Tauschtafelplan "Bruno" zu den Doppelbuchstabentauschtafeln fuer Kenngruppen,
# Kennwort: Quelle -- Pruefnr. 1772a.
#
# Source: photograph of the original published by Michael Hoerenberg,
# enigma.hoerenberg.com, "The Kenngruppen System (Navy)", file
# Tauschtafelplan_Bruno_Quelle.jpg.
#
# Rows are Monatstag, 1 to 31.  Columns are the six Kennziffer columns printed on
# the front, "eins" through "sechs"; the sheet is footed "Fortsetzung Rueckseite!",
# so further columns exist on the reverse and are NOT in the photograph.
#
# The sheet carries pencilled month labels over the columns -- eins "April 45",
# zwei "November", drei (illegible), vier "Februar 45", fuenf "Oktober", sechs
# "Mai 45" -- and pen corrections in columns eins, vier and sechs only.  Every
# correction replaces a printed C or H, consistently per column:
#     eins  C->E  H->G
#     vier  C->A  H->D
#     sechs C->G  H->B
# After correction those three columns use only A B D E F G J: C and H are gone
# from them entirely, while the uncorrected columns still contain both.  The
# obvious reading is that Tafeln C and H were withdrawn and a substitute named
# per column, but the sheet does not say so and that is inference, not evidence.
#
