# Kennwort: Flusslauf -- Pruef-Nr. 3633.
#
# Source: cryptomuseum.com/crypto/codebook/files/DoppelTafeln_Flusslauf_3633_992.pdf,
# pages 2 (Kennziffer eins-sechs) and 3 (sieben-zwoelf).
#
# The sheet is headed "Vorsicht!  Wasserloeslicher Druck!" and "Tritt erst auf
# besonderen Befehl in Kraft!", with the note that it is to be kept in the
# perforated cover belonging to the tables themselves.
#
# Clean print, no pen corrections, both sides reproduced.  The scan is 150 ppi --
# half the linear resolution of the Meer booklet -- so every cell here was read
# from the native image rather than from an upsampled render.
#
# This plan names FIFTEEN tables, A to P without I, where Quelle and Meer name
# nine.  Each column carries all fifteen letters, fourteen of them twice and one
# three times, which is 31 days; the exception is Kennziffer four, where K appears
# once and D and O three times each.  That column was read cell by cell twice and
# is irregular in the print, not in the transcription.
#
